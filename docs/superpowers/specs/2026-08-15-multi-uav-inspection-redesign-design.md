## 1. 背景与目标

### 1.1 单机项目（已发表，地基）
单机项目（ICC 2026）解决「单架蜂窝连接无人机巡检」的联合优化问题：同时决定**巡检序列**（IGA）与**飞行轨迹**（TD3），目标是最小化任务完成时间 + 传输时延，核心是**双无线电地图感知**（G2A 下行 + A2G 上行）。该工作是真实、自洽、已发表的，是本重构的**唯一可信地基**。

### 1.2 多机项目（要推倒重建）
多机是单机的期刊扩展，但现有 MultiUAV 项目存在两类问题：

**尚未实现（技术上的未完成项）**：轨迹层（MA-TD3）**尚未移植**单机论文的通信感知机制——观测里没有数据缓存、没有真实数据卸载（这些在单机里已实现，多机版还没做）；聚类权重待严谨化；序列边权公式与单机论文不一致。

**数据造假**（旧项目 `CLAUDE.md` 已诚实记录）：奖励曲线 2200 轮后是"模拟延长"、端到端指标被手动调整、三种聚类共用同一个模型导致结果相同、`regenerate_uav4_reward.py` 是调曲线工具。

### 1.3 目标
在全新目录下，基于单机项目**已发表、已验证**的通信模型，重构一套**真实、可复现、可辩护**的多无人机三层巡检系统（代码 + 真实实验 + 真实图表），论文后置。

## 3. 问题建模

### 3.1 系统模型
- **N** 架无人机（N = 2/3/4），**K** 个巡检点（K = 20/30/40），4 km × 4 km 乡村区域。
- 通信模型**完全复用**单机项目的 3GPP RMa 信道模型 + 双无线电地图。
- **关键建模假设（必须白纸黑字写进论文）**：各无人机占用正交时频资源，互不干扰，因此每架无人机的通信模型与单机完全一致；多机耦合**仅体现在空间碰撞避免**。

### 3.2 优化问题
最小化：

```
目标 = makespan T = max_i T_i   +   λ_E · 总能耗 E_total = λ_E · Σ_i E_i
```

其中 `E_i = ∫_0^{T_i} P(v_i(t)) dt` 为第 i 架无人机的飞行能耗（旋翼功耗模型，见 §3.4）；`λ_E` 将能耗折算为时间成本（单位 s/J）。

**决策变量**（三层耦合）：分配（点 → 无人机）、序列（簇内顺序）、轨迹（路径 + 传输调度）。

**约束**：
- (C1) 单扇区关联：`Σ_m ρ_m[n] ≤ 1`
- (C2) 传输时延 QoS：`τ_k ≤ τ_max, ∀k`（每个巡检点数据在 τ_max 内卸载完）——**时延作为约束而非目标**，这是相对单机论文的关键差异
- (C3) 中断时长上限：`T_out ≤ T_out^max`
- (C4) 运动学：`||q[n+1] − q[n]|| ≤ v_max·Δt`
- (C5) 边界条件
- (C6) 每个点唯一被访问一次
- (C7) 无人机间无碰撞
- (C8) 能耗预算（可选）：`E_i ≤ E_battery`

### 3.3 通信模型（复用单机已验证代码）
- **G2A 下行**：`γ_G2A_m = P_m·|h_m|² / (σ² + Σ_{j≠m} P_j·|h_j|²)`，低于阈值 `γ_min` 即中断。
- **A2G 上行**：`γ_A2G_m = P_u·|h_m|² / σ²`，速率 `R_m = B·log2(1 + γ_A2G_m)`。
- **数据卸载**：`D_k = Σ_n Σ_m ρ_m[n]·R_m[n]·Δt`，`τ_k` 为卸载 `I_i` 位所需时间。
- **最优信道关联**：`ρ_m[n] = 1` 当 `m = argmax γ_A2G_m`。

### 3.4 能耗模型（旋翼无人机）

采用经典旋翼无人机功耗模型（Zeng 等人）：

```
P(v) = P_0(1 + 3v²/U_tip²) + P_i·√(√(1 + v⁴/(4v₀⁴)) − v²/(2v₀²)) + (1/2)·d₀·ρ·s·A·v³
```

参数（文献标准值）：`P_0 = 79.8563 W`（桨叶剖面功率）、`P_i = 88.6279 W`（诱导功率）、`U_tip = 120 m/s`、`v₀ = 4.03 m/s`、`d₀ = 0.6`（机身阻力比）、`ρ = 1.225 kg/m³`、`s = 0.05`（旋翼实度）、`A = 0.503 m²`（旋翼盘面积）。

- 边 (i,j) 以速度 v 飞行能耗：`E_ij = P(v)·(d_ij/v)`。
- 无人机 i 总能耗：`E_i = Σ_边 P(v)·Δt`。

> 该模型在单机 `GA_EQTSP.py` 的 `power(v)` 中已存在（但单机论文正文未使用），多机重构将其**正式纳入优化目标**。

## 4. 关键事实：单机论文正文与代码的边权差异（诚实记录）

核查单机已发表代码后，发现两处正文/代码不一致，多机重构时**按"论文声称的物理意图"实现，并修复这些不一致**：

1. **序列边权**：论文正文写 `ψ_ij = C_ij/(d_ij·t_ij)`（且"最小化"存在符号笔误），但代码 `GA_EQTSP.py` 实际用 `weight = Data_size × Energy / Throughput`，再乘距离，且**代码里未使用 G2A 中断**（只有 A2G 吞吐 + 能耗）。
2. **轨迹层 G2A**：单机 `World.py` 中 G2A 中断惩罚被注释掉，仅 A2G 数据卸载真实启用。

**结论**：单机论文"声称"双地图感知，但代码只部分实现。多机重构的目标之一是**把双地图感知在三层里真正、一致地落地**——这既是诚实要求，也是相对单机的真实增量贡献。

## 5. 总体架构与数据流

```
 输入：K 个点(坐标/数据量 I_i) + G2A/A2G 无线电地图 + GBS 部署
        │
  层1  通信感知任务分配  (点 → 无人机)            [k-means 系 → 阶段二 GNN]
        │   每架无人机的点簇
  层2  通信感知序列      (簇内排序)              [GA_EQTSP → 阶段二 注意力模型]
        │   每架无人机的访问顺序
  层3  通信感知轨迹      (TD3 + 真实数据卸载)     [参数共享独立 TD3]
        │   轨迹、时延、中断、吞吐
  真实日志(JSON/NPZ) → 图表(纯自动生成，禁止手动调整)
```

**贯穿主线**：每一层都同时感知双无线电地图（G2A 下行 + A2G 上行）与能耗，这是论文核心创新；深度学习只是各层的求解器。

## 6. 三层详解

### 6.1 第 1 层：通信感知任务分配

**目标函数（严格）**：最小化

```
Σ_j [ 空间紧凑度_j + λ_g2a·Var(簇内 G2A 中断) + λ_a2g·Var(簇内 A2G 速率) + λ_vol·Var(簇内数据量) ]
```

约束：簇大小均衡 `|C_j| ≈ K/N`。

> "空间紧凑度"同时是**能耗均衡**的代理（路径越短能耗越低）；"数据量均衡"服务于**时延 QoS**（数据量越大越难满足 τ_max）。能耗与时延约束由此进入分配层的考量。

- **阶段一实现**：4D k-means（在增强特征空间 [空间, G2A, A2G, 数据量] 上做 k-means + 容量约束后处理）。权重 `λ` 不再是拍脑袋，而是**由端到端真实目标（makespan + 时延）调参**，并做灵敏度分析。
- **阶段二实现**：GNN 学习式分配（节点特征 = 坐标 + G2A + A2G + 数据量，输出软分配），直接学最小化上述通信感知代价。

**基线**：普通 k-means（仅空间）、balanced k-means（空间 + 容量均衡）、Jia 式（空间 + 负载均衡，无通信地图）。

### 6.2 第 2 层：通信感知序列（每架 EQTSP）

**边权（对齐目标 min T + λ_E·E，含约束惩罚）**：

```
cost_ij = d_ij / v_max  +  λ_E · E_ij  +  λ_out · t_ij  +  λ_τ · max(0, τ_ij − τ_max)
```

- `d_ij / v_max`：飞行时间（→ makespan）。
- `E_ij = P(v)·d_ij/v`：边能耗（→ 目标能耗项）。
- `t_ij`：沿直线路径采样的 G2A 下行中断时长（→ 中断约束惩罚）。
- `τ_ij = Data_size / C_ij`：边传输时延，`max(0, τ_ij − τ_max)` 为时延 QoS 违约惩罚（→ 时延约束）。
- `λ_E, λ_out, λ_τ`：权重，有明确物理含义，由端到端真实目标调参 + 灵敏度分析。

> 该式把"避开低 G2A 覆盖、偏好高 A2G 速率（满足时延 QoS）、省能耗、缩短飞行时间"的意图，落成与目标/约束一一对应的边权，并真正引入 G2A（修复单机代码缺 G2A 的问题）。

- **阶段一实现**：GA_EQTSP（修正边权；GA 框架沿用单机 `GA.py`）。
- **阶段二实现**：注意力模型（Kool et al. 2019, "Attention, Learn to Solve Routing Problems!"），直接学这个通信感知代价。

**基线**：GA（纯欧氏）、PSO、ACO、最近邻 + 2-opt。

### 6.3 第 3 层：通信感知轨迹（推倒重来的核心）

- **算法**：**参数共享的独立 TD3**（一个共享 actor+critic，每架无人机用局部观测独立决策；不用 MA-TD3 共享 Critic）。
- **状态 `s_i`**：`[自身位置, 目标相对位置, 数据缓存 I_i, 剩余时间, 其他无人机相对位置(避碰)]`。**关键：把单机论文的"数据缓存"加入状态**（旧多机观测里尚未实现）。
- **动作 `a_i`**：`[速度 v, 航向 θ]`，与单机一致，`v ∈ [0, v_max]`、`θ ∈ [0, 2π]`。
- **数据卸载（真实仿真，逐点数据量 `I_i`）**：每步 `data_size -= R_A2G·Δt`（最优信道关联），算真实传输时延 `τ_k`。
- **奖励**：`r_n = R_到达 + R_完成 − P_能耗 − P_传输 − P_中断 − P_碰撞`
  - `R_到达` / `R_完成`：到达目标 / 完成全部任务的稀疏奖励。
  - `P_能耗`：飞行能耗惩罚（`∝ P(v)·Δt`，鼓励节能飞行）。
  - `P_传输`：时延 QoS 违约惩罚（`τ_k > τ_max` 时惩罚）。
  - `P_中断`：飞入低 G2A 覆盖区的惩罚（**启用**，修复单机注释掉的部分）。
  - `P_碰撞`：与其他无人机过近的惩罚。

**对比基线（轨迹层）**：非通信感知的基线轨迹（如直线/贪心航点跟随，不感知地图、不主动优化卸载），用于证明轨迹层的通信感知收益。

## 7. 实验框架

### 7.1 三层各对比 + 端到端

| 层 | 基线 | Proposed（阶段一 → 阶段二） |
|---|---|---|
| 分配 | 普通 k-means、balanced k-means、Jia 式 | 4D 通信感知 → GNN |
| 序列 | GA(纯欧氏)、PSO、ACO、最近邻+2-opt | GA_EQTSP 通信感知 → 注意力模型 |
| 轨迹 | 非通信感知基线轨迹 | 通信感知 TD3 |
| 端到端 | 三层基线组合 | 三层 Proposed 组合 |

### 7.2 指标（真实计算，不手工调整）

- makespan `T = max_i T_i`
- 总传输时延 `τ_total`
- 上行平均速率
- 下行中断时长
- 总能耗 `E_total`（各无人机能耗之和）

### 7.3 可复现与防造假（硬约束）

1. 固定随机种子（环境、算法、训练）。
2. 保存模型、轨迹、原始日志（JSON/NPZ），图表**仅由原始日志自动生成**。
3. **禁止任何手动调整**——指标、曲线、图全部来自日志的一次性计算。
4. 环境 / 数据卸载 / 避碰 / 无线电地图查询各写**单元测试**，先验证物理正确再训练。
5. 所有命令可复现（一条命令出对应图表）。

### 7.4 明确删除（不迁入新项目）
`regenerate_uav4_reward.py`、奖励曲线"模拟延长"、被手动调整的端到端指标、"三种聚类共用同一模型"的结果——**全部删除**，用真实重跑替换。
