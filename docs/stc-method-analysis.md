# STC-ALNS 方法复杂度与精确基准说明

## NP-hard 归约

联合问题包含多旅行商 / 车辆路径子问题：当扇区带宽无限（无争用）、上传时延为零时，
问题退化为带共同起点/终点的多旅行商路径问题（mTSP），因此是 NP-hard。

## 离散候选空间的精确基准

`solve_exact_tiny` 在**离散候选空间**内穷举：任务分配（每个点归一架 UAV）、访问顺序
（每路线内排列）、航段候选选择、起飞时移。它返回该离散空间内的最优可行解，并设置
`proven_optimal=True`（当在时间限制内完成穷举时）。

**注意**：该最优性是"离散候选空间内最优"，不代表连续空间全局最优。

## 可采纳下界

下界采用"无争用"松弛：每架 UAV 独立按单机候选代价求最短路，忽略共享带宽争用。争用只会
增加时延/makespan，因此该下界可采纳（admissible）。

## 规模与失效点

- 穷举的复杂度为 O(U^K · (K/U)! · c^E · d^U)，随 K 快速爆炸。
- 实测在 K≤8、U≤2、候选受限时可在时间限制内完成；超过后需分支定界或 CP-SAT/MILP。
